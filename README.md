## Featured work

### 🎾 [TennisRank AI](https://github.com/suhaslord/tennisrank-ai)
A mobile-first ranking system that ingests flexible spreadsheet data, automatically interprets match/roster formats, calculates singles and doubles rankings, and persists data through Supabase.

`JavaScript` `Supabase` `Vercel` `Data Parsing` `Product Engineering`

### 🧠 [AbstainBench](https://github.com/suhaslord/AbstainBench)
A local-first benchmark for studying **when a language model should answer and when it should abstain**. Tracks accuracy, hallucinations, false abstentions, and category-level behavior, with an optional in-browser LLM through WebLLM.

`AI Evaluation` `WebLLM` `WebGPU` `JavaScript` `Research Tooling`

### ◌ [ECHO / FIELD](https://github.com/suhaslord/ECHO-FIELD)
A browser-native generative instrument where motion, voice, and memory alter a live visual field. Built with Canvas and the Web Audio API rather than pre-rendered visuals.

`Canvas` `Web Audio API` `Generative Systems` `Frontend`

### 🧩 [Portfolio](https://github.com/suhaslord/portfolio)
A responsive personal portfolio focused on technical projects, engineering work, and clean frontend design.

`HTML` `CSS` `JavaScript` `UI Design`

## Research direction

I’m currently building toward work in **aerospace autonomy and computational engineering**.

Areas I want to explore more deeply:

- autonomous UAV navigation and fault recovery
- safety and reliability in learning-enabled systems
- computational fluid dynamics and aerodynamic modeling
- flight controls and sensor-driven decision making
- multi-fidelity simulation and surrogate modeling

My goal is to turn these interests into **real experiments, reproducible code, technical reports, and open-source research projects**.

## What I care about

I’m less interested in building demos that only look impressive and more interested in answering questions like:

> **Does it actually work? How do we know? What happens when the assumptions fail?**

That means testing, measuring, documenting limitations, and improving the system instead of stopping at the first successful result.
